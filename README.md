Maven Central Publishing Plugin
===

This is a fork of Sonatype's central-publishing-maven-plugin. The creation of the HTTP client has been patched to
respect HTTP proxy system properties.

See https://central.sonatype.org/publish/publish-portal-maven/ for more information on how to use the plugin.
